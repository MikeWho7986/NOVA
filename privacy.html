Privacy policy

Nova - personal assistant. Last updated: 25 November 2026.

Who uses Nova

Nova is a private assistant used only by its owner, on the owner's own computer. It is not offered to the public, and no other person's data is accessed.

What Google data Nova accesses

With the owner's consent, Nova requests read-only access to:

  • Gmail - to read recent email for the owner's morning briefing and to answer the owner's questions about their email;
  • Google Calendar - to read upcoming events;
  • Google Tasks - to read the owner's task lists.

Nova cannot send, edit or delete email, events or tasks.

How the data is used and stored

  • Data is processed and stored only on the owner's computer, in a local search index used to answer the owner's own questions.
  • The AI model that reads it runs locally on the same computer. No Google user data is sent to any other server or AI service.
  • Data is never sold, shared with, or transferred to anyone.
  • Data is not used for advertising, and is not used to train any AI or machine-learning model.

Limited Use

Nova's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Locally stored data is deleted by removing Nova's data folder from the owner's computer.

Contact

Questions about this policy can be raised through this site's GitHub repository.
